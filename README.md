### 🔬 What I'm building

- **🔍 [Rogue Agent Checker (RAC)](https://github.com/richknowles/RogueAgentChecker)**: Finds the AI agents nobody told you about. Read-only PowerShell that inventories AI agents on Windows (Claude Code, OpenClaw, Codex, MCP servers, homemade bots), checks them against your allow-list, and hands you a report you can give to an auditor. Tested live against a staged rogue agent, misses included.<br>
  <a href="https://github.com/richknowles/RogueAgentChecker/releases/latest"><img src="https://img.shields.io/github/v/release/richknowles/RogueAgentChecker?style=flat-square&label=release" alt="Latest release" /></a>
  <img src="https://img.shields.io/github/stars/richknowles/RogueAgentChecker?style=flat-square" alt="Stars" />
  <img src="https://img.shields.io/badge/license-Apache--2.0-blue?style=flat-square" alt="Apache-2.0" />
- **🦚 [Peacock](https://github.com/richknowles/peacock)**: Open-source Linux MCP server that gives Claude Desktop scoped filesystem access without letting it nuke your homedir. Sandboxed command execution, strict allow-listing, timeouts. Python/FastMCP.
- **📍 [pct-svcmap](https://github.com/richknowles/pct-svcmap)**: Go service discovery for Proxmox clusters. Throws goroutines at LXCs and VMs until it finds everything with a pulse and an open port.
- **👾 [POTA4](https://github.com/richknowles/POTA4)**: My MSP's RMM platform, built on Tactical RMM. Remote desktop, real-time shell, scripting, patch management and alerting.
